# Game2D

A lightweight Godot 2D mobile-game project, planned for Android ARMv7/32-bit compatibility.

## Project status

- [x] Initial technical plan added: [PLAN.md](PLAN.md)
- [ ] Confirm the exact game style and target-device capabilities
- [ ] Build a small playable MVP
- [ ] Import and test on the vivo Android device
- [ ] Verify ARMv7 APK export and installation

## Development constraints

- Godot 4.x stable, subject to the version installed on the target phone
- GDScript only; no C#/.NET
- Compatibility renderer where supported by the device
- Original or properly licensed art/audio
- No root permissions or mandatory desktop-only tooling

**Important:** The plan is not yet a completed game or tested APK. See [PLAN.md](PLAN.md) for milestones, structure, performance targets, and acceptance checks.
